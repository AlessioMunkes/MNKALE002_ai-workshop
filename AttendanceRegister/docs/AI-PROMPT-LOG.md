## Reflection prompts

Notes for the written reflection. These are questions to answer, not answers.

- Where did AI speed you up, and where did checking its output cost more time
  than writing the code yourself would have?
- Which decisions did you have to make that the AI could not, because it did not
  know the context — the DP rule, what a tutor actually does after a lecture,
  what a student number looks like at UCT?
- Where did the AI produce something plausible that was wrong? How did you catch
  it?
- What would you put in a departmental AI framework as a rule, based on this
  project?
